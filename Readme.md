# Kittygram

## Описание проекта

Kittygram — это веб-приложение для любителей котиков. Пользователи могут делиться фотографиями своих питомцев, ставить лайки и комментировать посты. Проект представляет собой социальную сеть, специализированную на котах и кошках.

### Основные функции

- Регистрация и аутентификация пользователей
- Создание, редактирование и удаление постов с фотографиями котиков
- Лайки и комментарии к постам
- Личный кабинет пользователя
- Админ-панель для управления контентом
- Адаптивный интерфейс

## Стек технологий

### Бэкенд
- **Python 3.10** — язык программирования
- **Django 4.2** — веб-фреймворк
- **Django REST Framework** — создание API
- **PostgreSQL 13** — база данных
- **Gunicorn** — WSGI-сервер

### Фронтенд
- **React 18** — библиотека для интерфейса
- **Node.js 18** — среда выполнения JavaScript
- **React Scripts** — сборка проекта

### Инфраструктура
- **Docker** — контейнеризация
- **Docker Compose** — оркестрация контейнеров
- **Nginx** — веб-сервер и обратный прокси
- **GitHub Actions** — CI/CD
- **Docker Hub** — хранение образов

### Инструменты
- **Ruff** — линтер для Python
- **npm** — менеджер пакетов для фронтенда
